Conditions du Pass Journée

Simples et sans surprise : 7 DT pour 24 heures, sans renouvellement automatique.

1. Le service

Le Pass Journée est vendu par l'éditeur du site « Outils pratiques Tunisie ». Il permet de faire autant de calculs que souhaité, pendant 24 heures, sur les 5 calculateurs du site : salaire brut ⇄ net, impôt sur le revenu, crédit, auto-entrepreneur et retenue à la source.

2. Ce qui reste gratuit

Sans Pass : l'exemple affiché à l'ouverture de chaque calculateur reste toujours visible, et chaque appareil a droit à 1 calcul personnel gratuit par jour (tous calculateurs confondus ; pendant 10 minutes, les chiffres de ce calcul peuvent être corrigés). Le lendemain, un nouveau calcul gratuit est disponible. Ce compte est gardé dans le navigateur du téléphone.

3. Prix

7 DT pour un Pass Journée de 24 heures, en dinars tunisiens. Le prix affiché au moment de la demande s'applique.

4. Paiement

Le formulaire de demande donne aussitôt à l'acheteur son code de commande (8 caractères). Paiement par D17 ou IZI au 24 321 390, avec pour motif ce code de commande, puis preuve envoyée par WhatsApp au même numéro (message déjà rempli avec le code). Après réception du paiement, ce même code est activé et devient le code d'accès, en général sous 24 heures ; l'activation est confirmée par WhatsApp. Si le code a été oublié dans le motif, la preuve envoyée par WhatsApp suffit pour retrouver la demande.

5. Durée : 24 heures à partir de l'activation

Le Pass dure 24 heures à partir de l'activation du code, c'est-à-dire du moment où le paiement est validé et le code de commande activé (et non du moment du formulaire). L'heure de fin exacte est écrite dans le message WhatsApp qui confirme l'activation. Le code peut mettre jusqu'à 10 minutes à fonctionner après l'envoi. Si un nouveau Pass est payé pendant qu'un Pass est en cours, les 24 heures s'ajoutent après la fin du Pass en cours (aucune heure perdue).

6. Pas de renouvellement automatique

Aucun renouvellement automatique : à l'heure de fin, le Pass s'arrête simplement et le site revient au calcul gratuit du jour. Rien n'est prélevé.

7. Arrêt

L'acheteur peut arrêter quand il veut en nous écrivant sur WhatsApp. Aucune période payée n'est remboursée.

8. Code d'accès

Le code d'accès est personnel : ne le publiez pas. Il est vérifié dans le téléphone et gardé sur l'appareil où il a été tapé (si le navigateur est vidé, il faut le retaper). Un code publié ou revendu peut être désactivé.

9. Limites

Les résultats sont indicatifs, calculés avec les règles officielles en vigueur. Ce site n'est pas un service officiel et ne remplace pas un comptable, un conseiller fiscal ou votre banque. Le Pass donne accès aux calculs, pas à un conseil personnalisé.

10. Données personnelles

Nous gardons seulement : nom, téléphone, e-mail, dates du Pass et code d'accès, dans un espace privé. Ces données servent uniquement à envoyer le code, ne sont jamais publiées ni vendues, et sont supprimées sur simple demande (WhatsApp). Sur le site public, il n'y a que l'empreinte non réversible du code et son heure de fin. Les chiffres tapés dans les calculateurs ne quittent jamais le téléphone. Le formulaire passe par le service Formspree. Sur le téléphone de l'acheteur, seule la commande en attente est gardée (code, formule et date, 60 jours au plus), jamais le nom, le téléphone ni l'e-mail. Ce traitement a reçu l'accord de l'INPDP (Instance nationale de protection des données personnelles).

11. Contact
