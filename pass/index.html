Comment ça marche ?

  1. Remplissez le formulaire ci-dessous (nom, téléphone WhatsApp et e-mail) : vous obtenez tout de suite votre code de commande.
  2. Payez 7 DT par D17 ou IZI avec ce code pour motif du paiement, et envoyez la preuve par WhatsApp (message déjà rempli).
  3. Dès que votre paiement est reçu, nous activons ce même code (en général sous 24 heures) et vous confirmons l'heure de fin par WhatsApp.
  4. Revenez sur cette page depuis le même téléphone : le code est essayé tout seul (ou tapez-le une fois dans « J'ai un code »). Tous les calculs sont débloqués pendant 24 heures.
